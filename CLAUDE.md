## What This Repo Is

This is the **paper repo**. It integrates all previous phases into a single
end-to-end CPU-native video generation pipeline:

1. **Mamba SSM backbone** (Phase 2) — O(n) sequential processing
2. **Codec temporal design** (Phase 3) — I-frame/P-frame generation
3. **1-bit quantization** (Phase 4) — binary weights, minimal memory
4. **Portable SIMD execution** (Phase 5) — native CPU kernels on x86 (AVX2) and ARM (NEON)
5. **Distributed training** (Phase 6) — evolution strategies across laptops

Everything here is CLEAN, DOCUMENTED, and REPRODUCIBLE. This is what
reviewers see, what Arxiv readers clone, what PhD committees evaluate.

### Key Claims

1. First video generation model trainable and runnable entirely on CPU
2. Codec-inspired temporal design reduces compute 4-6×
3. Mamba SSM replaces O(n²) attention with O(n) scan
4. 1-bit quantization enables XNOR+popcount on CPU integer ALUs
5. Portable SIMD kernels (AVX2 + NEON) achieve N× speedup over PyTorch on both x86 and ARM
6. Distributed training via evolution strategies across commodity hardware

## Hardware Target

The paper's **benchmark reference** is the Pentium Gold — the canonical thesis machine. Development
happens on a **MacBook Air M4 (ARM64)** (the original Pentium laptop was retired). Both are first-class
CPU-native targets: the portable SIMD library (Phase 5) runs on x86 via AVX2 and on ARM via NEON, so
the paper reports CPU-native results on **both** architectures.

| Spec | Benchmark target | Dev machine |
|------|------------------|-------------|
| CPU | Intel Pentium Gold 7505 (2C/4T, 3.5 GHz, x86-64 AVX2) | Apple M4 (ARM64, NEON) |
| RAM | 16 GB DDR4 | 16 GB unified |
| GPU | None (CPU-only) | Unused (CPU-only) |
| SIMD backend | AVX2 | NEON |

> Target principle: *if it runs on a Pentium Gold, it runs everywhere.*
